# PULSE Engineering

Engineering diagnostic layer for PULSE Machine Connect.

This implementation provides a browser-ready diagnostic workspace and a deterministic diagnostic engine that can later be connected to Supabase Edge Functions or a NestJS API.

It follows the uploaded PULSE Engineering specification: machine evidence, telemetry-based fault inference, safety guidance, and procedure execution. The current inference is intentionally rule-based and should not be treated as a safety-critical diagnostic system.
